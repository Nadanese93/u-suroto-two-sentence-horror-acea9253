# Two-Sentence Horror

A two-sentence horror story in exactly 107 characters: a dollhouse in the attic holds a tiny figure standing in every room — until this morning, when there was one in my room. The second sentence turns the first, placing the narrator inside the miniature and leaving the horror entirely implied, never explained.
